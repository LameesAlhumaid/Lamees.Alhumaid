# SANED | AI-Powered Platform for Proxy Hajj and Umrah
SANED is an AI-powered digital platform designed to facilitate secure and structured Hajj and Umrah services on behalf of elderly individuals, people unable to perform the rituals themselves, and deceased individuals.
# My Role
I initiated the original project idea and contributed to the platform development as part of a team. My work included:
- Frontend development
- Backend development
- Prompt engineering for the AI assistant
- Academic research and documentation
- Prototype and poster preparation

# Key Features
- AI chatbot for Hajj and Umrah inquiries
- Real-time volunteer tracking
- Secure user-volunteer communication
- Volunteer verification
- Dynamic ritual reports
- User-friendly interface
